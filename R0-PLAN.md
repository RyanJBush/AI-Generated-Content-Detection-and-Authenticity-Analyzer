## What R0 delivers

A tested skeleton that accepts a file, classifies it, builds a segment tree, runs **placeholder analyzers that always return `inconclusive` / `not_supported` with reasons**, and writes a valid report. No detector, no models, no datasets, no C2PA analysis results.
